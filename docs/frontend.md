# 使用监测控制台

监测控制台与 FastAPI 同进程提供服务，读取项目已有的美国站服装监测数据。前端使用原生 HTML、CSS 和 JavaScript 模块，无需 Node.js 构建步骤。

## 启动并打开页面

先按 [运行指南](runtime-guide.md) 配置现有数据库和 Python 环境。在项目根目录运行：

```powershell
.\.venv\Scripts\python.exe -m scripts.run_api
```

默认页面入口是 <http://127.0.0.1:8000/>；API 文档仍在 <http://127.0.0.1:8000/docs>。主机和端口复用现有 `API_HOST`、`API_PORT` 和 TOML 配置。启动 API 不会建表、导入种子或启动采集任务。

页面通过同源 `/api/v1` 请求读取数据，不需要在浏览器里配置数据库地址或写入令牌。应通过 API 服务打开页面，JavaScript 模块及相对 API 地址需要 HTTP 环境。

## 查看监测页面

控制台左侧导航使用 URL 片段切换，刷新和直接打开指定页面都复用根入口。默认进入数据工作台。

| 页面 | 地址 | 查看内容 |
| --- | --- | --- |
| 数据工作台 | `/#workbench` | 五个分析主题、统一筛选、图表下钻、字段与历史覆盖 |
| 市场总览 | `/#overview` | 店铺与商品规模、价格和变化概况 |
| 店铺监测 | `/#shops` | 已采集店铺和公开入口 |
| 商品监测 | `/#products` | 商品价格、库存、属性和 SKU，批量选择与商品对照 |
| 竞品匹配 | `/#matches` | 规则候选、人工确认同款、精确 SKU 映射、持久保存与撤销 |
| 变化事件 | `/#events` | 商品、价格、库存及规格的变化记录 |
| 采集任务 | `/#tasks` | 任务类型、状态、进度和执行尝试 |
| 监测报告 | `/#reports` | 按观察区间汇总的监测结果 |

页面顶部可刷新数据。总览、商品、事件与报告页面可选择最近 24 小时、7 天或 30 天的事件观察区间；商品与店铺价格统计仍使用最新可重建观察。底部标注北京时间和当前币种。

2026-10-14 按用户提供的[设计参考分享](https://chatgpt.com/share/6acf73a0-3bb0-83ea-8f65-707c547b3bec)与四张截图调整界面：商品页参考 Pickolab / Metricly 的紧凑商品工作台，总览参考 Parklins / Funnelish 与 Polar 的趋势图、环图、排行和分组指标。采用浅灰外画布、白色工作区、蓝色操作重点与细分隔线。

总览提供监测概览、价格分析和监测质量三个主题。主趋势统计窗口内实际观察到的变化事件；价格分析使用公开价格下限，库存环图只覆盖已观察 SKU。鼠标停在图中的采样点可查看时间与数量，图表不推算销量或成交额。

商品监测提供表格和网格视图、可排序列、显示列设置、每页 10/20/50/100 条、当前页全选、跨页选择、筛选视图保存及选中商品导出。筛选视图和列偏好仅保存在当前浏览器，不创建后端配置。选中 2–4 件商品可查看公开起价差与真实历史轨迹；首个勾选商品作为起价基准。对照注明币种、价格口径、颜色与尺码，不能自动确认这些商品具有相同规格。

## 页面入口与资源

| 地址 | 内容 | 实现位置 |
| --- | --- | --- |
| `/` | 监测控制台入口 | `app/frontend/index.html` |
| `/ui-assets/styles.css` | 响应式页面样式 | `app/frontend/styles.css` |
| `/ui-assets/app.js` | 页面渲染和交互 | `app/frontend/app.js` |
| `/ui-assets/api.js` | 同源请求、格式化和 CSV 导出工具 | `app/frontend/api.js` |

静态目录由 `app/main.py` 的 `__file__` 解析，因此资源定位不依赖启动时的工作目录。静态挂载限定在 `app/frontend/`，不会把项目根目录暴露为可下载资源。既有 `/api/v1`、健康检查、指标和 API 文档路由保留原有地址。

Dockerfile 的 `COPY app ./app` 会包含前端资源；通过 Python wheel 分发时，`pyproject.toml` 的 package-data 配置也包含 HTML、CSS 和 JavaScript 文件。此说明基于文件配置检查，未代表 Docker 镜像已经构建验收。

## 数据接口与口径

| 数据 | 只读接口 | 使用说明 |
| --- | --- | --- |
| 市场和采集能力 | `GET /api/v1/capabilities` | 当前范围与启用的任务类型 |
| 店铺、商品及任务数量 | `GET /api/v1/overview` | 服务端返回的范围内总量 |
| 店铺列表 | `GET /api/v1/shops` | `with_url` 可选；`limit` 和 `after_id` 游标分页 |
| 商品列表 | `GET /api/v1/analytics/products` | 服务端搜索、筛选、排序与分页；批量关联真实首图 |
| 多维工作台 | `GET /api/v1/analytics/workbench` | 数据库完整筛选范围的聚合、中位数、服装属性、规格矩阵和质量统计 |
| 商品图片 | `GET /api/v1/products/{id}/images` | 真实公开图库、图片来源与观察时间；缺图与缺表分别标识 |
| 同款与 SKU 关系 | `GET /api/v1/matches`、`GET /api/v1/matches/candidates` | 查询持久关系和限定范围的规则建议 |
| 商品属性和 SKU | `GET /api/v1/products/{id}`、`GET /api/v1/products/{id}/variants` | 查看颜色、尺码及当前采集状态 |
| 历史快照 | `GET /api/v1/products/{id}/snapshots` | 按游标读取历史价格和库存证据 |
| 变化事件 | `GET /api/v1/reports/current` | 窗口内事件及前后快照标识；超过 1,000 条会提示截断 |
| 采集任务和执行尝试 | `GET /api/v1/tasks`、`GET /api/v1/tasks/{task_id}/attempts` | 使用任务类型、状态及每次尝试结果 |
| 当前监测报告 | `GET /api/v1/reports/current` | 支持 `lookback_hours=1..720` 和 JSON、HTML、Markdown 格式 |
| 归档报告 | `GET /api/v1/tasks?task_type=report_generation`、`GET /api/v1/reports/jobs/{task_id}/files/{format}` | 查询报告任务，下载已完成任务的 HTML、JSON、Markdown 文件 |

数据库 ID 和分页游标按字符串处理，避免 JavaScript 大整数精度丢失。前端日期显示为北京时间；金额使用记录所属币种。缺失金额、数量和时间显示为空值提示，不能用零代替未知数据。商品起步价、价格区间和 SKU 精确价格应按各自含义阅读，详细统计口径见 [监测报告说明](monitoring-reports.md)。

服务暂不可用时会显示请求失败状态。空列表意味着该查询没有返回记录；请求失败、部分分页结果和采集全覆盖分别有不同含义。当前报告失败时，店铺采样数量显示未知并禁用采样筛选，独立可用的归档报告仍可查看。快照请求失败会显示读取错误，不会表示没有历史观察。

匹配页面的确认和撤销使用 `POST/PATCH /api/v1/matches`。用户需连接服务中已配置的 API 写入令牌，令牌只保留在当前页面内存，刷新即清除。写接口未启用时仍可读取分析；写入请求会明确返回状态。真实同款关系不会仅由规则评分自动确认，SKU 的颜色、原始尺码及完整选项需通过校验。

## 验证入口和资源

使用项目虚拟环境运行静态入口测试：

```powershell
.\.venv\Scripts\python.exe -m pytest tests/test_frontend.py -q
```

测试使用注入的禁止数据库连接对象和显式配置，运行 FastAPI lifespan，但不读取本地凭据、不建立数据库连接。测试覆盖从其他工作目录创建应用、根页面响应、样式与模块 MIME 类型、静态目录边界、未知 API 的 404 和既有路由注册。

此测试只验证 HTTP 入口与资源分发，不代表浏览器交互、真实数据库统计、采集覆盖率或容器部署已经通过。页面交互和真实数据验证应以本次实际浏览器检查记录为准。

2026-10-14 使用独立 Chrome 浏览器读取本地服务，已验证六个页面及真实数据：100 个可访问店铺入口、120 件商品、3 家有商品采样的店铺，公开起价中位数 USD 40.29。这些数字是本次检查的观察结果，会随采集更新。

浏览器检查覆盖店铺搜索及采样筛选、店铺跳转关联商品、商品搜索与库存筛选、颜色尺码和 SKU 详情、历史快照、事件依据、任务分页与执行详情、观察窗口切换、CSV 与 JSON 报告下载。修复并复查了搜索输入引发的嵌套渲染错误，中文输入法合成期间保留输入节点。手机导航关闭时通过 inert 排除隐藏导航的键盘焦点；390px 宽页面无整页横向溢出，表格在自身容器内横向滚动。
