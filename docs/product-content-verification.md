## 性能与发布边界

商品 ID 游标应用完整筛选范围，再按 128 个商品投影当前 SKU ID，SKU 每批流式读取 1,000 行。高 ID 小店铺测试在两种数据库上均不超过 6 条 SELECT，不扫描所有无关商品。工作台不创建临时表，也不把全量 ORM 对象装入内存。

开发期间曾在本机合成 18,000 个商品、666,000 个保留 SKU、612,000 个当前 SKU，完整工作台读取约 34.78 秒，进程峰值约 123.63 MiB。该测量早于最后的筛选游标修正，而且包含构造测试数据的内存，不能视为最终生产性能或 VPS 保证。

真实平台的独立 Introduction、AI 问答、原生图片对象和尺码表形状仍须通过正常采集响应确认。已知 HTML 图文合同支持完整保存；未知形状保留 partial，不猜字段、不用任务成功替代资料完整度。服务器部署与真实补采由原发布任务统一验收。
